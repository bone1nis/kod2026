# 2 - Врата · Три символа

Статичная сцена у Врат до начала сканирования: на камнях замка лежат три незнакомых символа и мягко светятся. Кнопки сканирования и расшифровки нет.

HTML и CSS, без JavaScript и библиотек. Запуск: открыть `index.html` в браузере.

- `index.html` - разметка сцены: фон и три глифа в общем контейнере
- `styles.css` — позиционирование символов и свечение `box-shadow`
- `img/` — фон и SVG-символы

Сцена держит пропорции фона 16:9, размер и положение символов заданы в процентах от контейнера, поэтому они остаются на камнях при любом размере окна.
