# 3 - Сокровищница · Симметрия созвездия

Функция `isSymmetric(symbols)` проверяет, симметрична ли последовательность символов на двери сокровищницы. Символы показаны звёздами. По кнопке «Рассчитать» пары, стоящие на одинаковом расстоянии от краёв, по очереди подсвечиваются: золотым, если совпали, красным, если нет. В конце появляется итог: "Дверь открывается!" или "Созвездие нарушено". Набор символов можно выбрать из готовых или ввести свой.

HTML, CSS, JavaScript, без библиотек. Запуск: открыть `index.html` в браузере. Результат также печатается в консоль (или `node script.js`).

- `index.html` - разметка сцены и панели
- `styles.css` — оформление и анимации: свечение звёзд, дрожание несовпавших пар через `@keyframes`, выпадающий список и поле ввода
- `script.js` — функция `isSymmetric` (сравнение по позициям, без `reverse()`), пошаговая проверка через `setTimeout`, разбор введённого кода
- `img/` — фон

Свой код: от 1 до 9 целых чисел через пробел, запятую или `;`. Готовые наборы из списка — 6 тестов из задания.
